# 再スキャンと修正の確認

[English](../rescan.md) · **日本語**

監査する側は修正を行いません。利用者が指摘事項を修正し、そのあとスキルに修正の確認を頼みます。これが Phase 8 で、依頼されたときだけ実行します。

## 実行するタイミング

監査したリポジトリに修正を入れたあと、同じ監査の文脈で、たとえば次のように頼みます。

```text
修正を確認するために再スキャンして
FIND-SHOPAPI-001 から 004 を修正したので確認して
re-scan to verify the fixes
```

Phase 8 には監査の `work/` フォルダが必要で、既定の整理では残してあります。`--purge-work` で監査した場合は、スキャナのピンと正本の指摘事項が残っていないため、再スキャンは新しい監査になります。

## 実行する内容

1. **同じイメージでスキャナを再実行する。** リポジトリごとに `run_scanners.py` が `work/<repo>/rescan-<新しい日時>/` に書き出します。どのスキャナも、最初の実行の `scanners.json` に記録した正確な `image:tag@sha256` に固定します（`--pin tool=...`）。そのあと、そのフォルダに対して `normalize_findings.py` を実行します。
2. **手作業で見つけた指摘をすべて読み直す。** 各 `path:line` アンカーを、現在のコードでもう一度開きます。
3. **正本で状態を更新する。** `status` と `verified` を `work/findings.json`（他の言語では各 `findings_<L>.json`）で変更します。`findings/<lang>/*.md` を手で直しても次の再生成で上書きされるため、JSON が変更する場所です。
4. **報告書を一式作り直す。** 言語ごとに、`new_finding.py --force`（翻訳した一式では `--source` 付き）、`build_report.py --force --fill`、`validate_findings.py`、選んだ HTML と Excel の描画を実行します。

## 指摘が閉じる条件

指摘が閉じるのは、次の 2 つがどちらも成り立つときだけです。

- **再現しなくなった**：スキャナがもう報告しない、または読み直して欠陥がなくなったことを確認した。
- **検出したルールがまだある**：同じスキャナのイメージが、その指摘を見つけたルールを今も出力する。つまり、検出されないのはルールが変わったせいではない。

「直しました」という申告だけで指摘を閉じることはありません。`accepted-risk` と `false-positive` は、利用者の判断と理由を記録したときだけ設定します。

```text
open -> （利用者が修正） -> 同じイメージダイジェストで再スキャン（手作業の指摘は読み直し）
     -> 再現する？  はい -> open のまま
                    いいえ -> 検出ルールはまだある？ -> closed
```

## 同じダイジェストが重要な理由

再スキャンに新しいスキャナを使うと、コードが直ったからではなく、ルールが変わったために指摘が消えることがあります。ダイジェストで固定すれば、再スキャンは最初のスキャンとまったく同じスキャナで動きます。ただし、ルールパックと脆弱性データベースはイメージのタグとは別に更新されます。

そのため、次のものは変わることがあります。

- **オフラインモード**（`--offline`）は Trivy と zizmor のデータベースを固定しますが、OSV-Scanner は実行しません。OSV や `MAL-*` の指摘は、OSV-Scanner をオンラインで再実行して確認します。
- **Semgrep の `p/default`** のルールパックはオフラインでも取得するため、固定されません。スキルは、閉じる指摘のルール ID がまだ出力されることを確認します。

## 報告書で変わるもの

作り直した報告書には新しい状態と `verified` の日付が入り、Excel の Summary の状態別のグラフと件数もそれに従います。作り直したブックは同じパスにある以前のブックを置き換えるため、チームが担当者・期限・メモの列に入力している場合は、先にコピーを取り、その内容を移してください。再スキャンの出力は、最初の実行の隣の `work/<repo>/rescan-<ts>/` に残ります。
