# モジュール：public-sector - 政府機関と地方公共団体のシステム、およびそのクラウド事業者

コードが政府機関や地方公共団体に提供される場合、またはそれらに販売されるクラウドサービスである場合
（detect の業種 `government`：LGWAN、ISMAP、ガバメントクラウド、JPKI / マイナポータル、`*.lg.jp`、
`gov.vn`）、および重要インフラの事業者に適用する。バージョンは `reference/standards/index.md` に従う。

## 1. 適用される規則
| 正規名 | 内容 | 版 / 日付 | 対象 |
|---|---|---|---|
| `Japan Government Unified Standards` | 政府機関等のサイバーセキュリティ対策のための統一基準群（統一規範 / 統一基準 / ガイドライン） | 令和7年度版（2025-07-01）。ガイドラインの改定 2025-09-05 と 2026-06-12（すべてのシステムにパッチ管理を設計段階から組み込む、IT-BCP） | 中央省庁等。調達条件を通じて受託事業者 |
| `ISMAP` | 政府情報システムのためのセキュリティ評価制度（ISMAP、低リスクの SaaS 向けの ISMAP-LIU） | 運用中。管理基準の改定案が 2025-12 時点で策定中（状況は未確認） | 政府に販売されるクラウドサービス |
| `Japan Active Cyber Defense Act`（サイバー対処能力強化法） | 指定された重要インフラ事業者による、4 か月以内の資産の届出と、インシデントの速やかな報告（詳細な報告は 30 日以内） | 2025-05 成立。報告義務は 2026-10-01 施行と報じられている（二次情報） | 特別社会基盤事業者（電気、ガス、水道、運輸、電気通信、放送、金融、クレジットカード会社など） |
| `Vietnam Decree 85/2016` + Circular 12/2022/TT-BTTTT | レベル別の情報システムのセキュリティ（5 段階） | 施行中として掲載されているが、根拠法は 2026-07-01 に Cybersecurity Law 116/2025 に置き換えられ、後継の政令は見つかっていない - その注記を付けて引用する | ベトナムの国家システムと重要情報システム |
| `Vietnam Cybersecurity Law` | Law 116/2025/QH15 | 2026-07-01 施行 | ベトナムのサービス（対象サービスにはデータローカライゼーションとログ保持） |

## 2. コードから根拠を示せる確認項目
| ID | 確認項目 | 検証する内容 | 検出 |
|---|---|---|---|
| G01 | 管理者とリモートアクセスの MFA | IdP / 管理コンソールの設定、IaC の VPN / 踏み台の設定 | S+M |
| G02 | 設計段階からのパッチ管理（2026-06 のガイドライン改定） | 依存関係とベースイメージの自動更新、EOL の追跡（`intel.md`）、文書化された緊急パッチの経路（`reference/method/threat-intel.md` のパッチ対応力） | S+M |
| G03 | 承認された暗号 | CRYPTREC の電子政府推奨暗号リストに沿った TLS の設定とアルゴリズム。非推奨のプロトコルがない | S |
| G04 | ログ | ログの収集、時刻同期、保持と保護。重要インフラの事業者では、30 日以内に詳細なインシデント報告を提出できるだけの内容 | S+M |
| G05 | Web の基本対策 | URL に機微なデータがない、入力の検証、公開サイトのコンテンツ改ざん対策 | S+M |
| G06 | クラウドの設定 | ISMAP に登録されたサービスに沿ったサービスとリージョン。契約が求める場合は国内リージョンのみ。必要な場合は顧客管理の鍵 | S |
| G07 | 資産の台帳 | サーバーごとに製品、型番、バージョンを列挙できる IaC のタグまたは CMDB のエクスポート（サイバー対処能力強化法は事業者にこれらの届出を求める） | S |
| G08 | ベトナム | システムのセキュリティレベルが宣言され、その管理策（Decree 85 / Circular 12）がネットワーク分離、ログ、アクセス制御に反映されている。Law 116/2025 の対象サービスではデータローカライゼーションとログ保持 | M |

## 3. 重大度
- **P0：** 住民のデータ（マイナンバー、税、社会保障）に認可なしで到達できる。管理コンソールが MFA なしで
  インターネットに公開されている。
- **P1：** インターネットに面した政府システムにパッチの自動化や EOL の追跡がない。30 日以内のインシデント
  報告を支えられないログ。契約に反するリージョンや鍵の設定。
- **P2：** 内部の通信経路で承認リスト外の暗号や TLS の設定。
