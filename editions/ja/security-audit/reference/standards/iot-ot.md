# モジュール：iot-ot - 接続機器、産業制御、車両

リポジトリがファームウェア、機器やコンパニオンアプリのコード、OT / ICS との連携、車両のソフトウェアを
含む場合に適用する（detect の業種 `iot`、`ot`、`automotive`：MQTT、CoAP、BLE、OTA、RTOS / 組み込み Linux、
Modbus、OPC UA、BACnet、CAN、UDS、AUTOSAR）。バージョンは `reference/standards/index.md` に従う。

## 3. 重大度
- **P0：** ネットワーク上の攻撃者が機器や産業プロセスを制御できる既定の認証情報、または認証のない
  書き込み経路。署名のないファームウェアアップデートをネットワーク経由で受け入れる。
- **P1：** すべての機器で共有されるハードコードされたシークレット。本番ビルドで有効なデバッグ
  インターフェース。証明書の検証が無効。到達可能なエンドポイントで OPC UA のセキュリティモードが `None`。
- **P2：** 開示ポリシーや SBOM がない。署名はあるがロールバック防止のないアップデート。
